# ReviewLens

ReviewLens is a laptop review analysis project that helps users explore and analyse laptop reviews through a web-based interface.

The project combines a user interface with review-analysis and prediction components to make laptop review information easier to understand.

## Project Features

- Laptop,Mobiles and Tabs review analysis through a web interface.
- Device information and supporting dataset.
- Model-related and prediction interface pages.
- Web application built with HTML, CSS, JavaScript, and Python.

## Project Structure

- `web_app/` — application pages, frontend logic, styles, server, and device data.
- `ReviewLens.pptx` — project presentation.
- `ReviewLens_CaseStudy_Review2.docx` — project case study.
- `ReviewLense_IEEE_casestudy.docx` — IEEE-style case study.
- `SemEval2016_and_DeBERTaV3_Model_Paper_Dossier.docx` — research and model reference document.
